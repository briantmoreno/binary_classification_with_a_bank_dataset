# Predict whether a client will subscribe to a bank term deposit
## Project description
This belongs to Kaggle's Playground Series - Season 5, Episode 8 challenge to learn and sharpen skills in different aspects of machine learning and data science. The data provided for this, was generated from a deep learning model trained on the Bank Marketing Dataset.
## Goal
Create a machine learning model to predict whether a client will subscribe to a bank term deposit.
## Content
* Introduction
* Data preprocessing
* Exploratory Data Analysis (EDA)
* Machine learning models analysis
* Test data submission
## Reference
The dataset used for this project was obtained from Kaggle platform: Kaggle · Playground Prediction Competition. (2025). Binary Classification with a Bank Dataset [Data set]. Kaggle. https://www.kaggle.com/competitions/playground-series-s5e8/data
